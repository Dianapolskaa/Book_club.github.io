# Book_club
website with information about books
## Цель проекта: создать книжный каталог с возможностью просмотра популярных книг, каталогом произведений, хранением истории просмотренных книг, а такэе формой обратной связи.
## Используемые технологии:
 - HTML
 - CSS
 - JavaScript
 - JSON
 - LocalStorage
 - Модальные окна
 - Пагинация
 - Изменение темы сайта
